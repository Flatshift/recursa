# Security

Please report security problems privately, not in a public issue: use **Report a vulnerability** on the
[Security tab](https://github.com/flatshift/recursa/security) of the repository.

Include what you found, how to reproduce it, and the version (Settings › About, or `recursa --version`). We'll reply
within a week.

Recursa sends DNS queries to the resolvers you choose, and serves its browser interface only on 127.0.0.1 behind a
session token that the page gets by trading a one-time launch code. Reports about either are especially welcome.
