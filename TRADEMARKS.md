# Trademarks

Recursa and the Recursa icon (the Cantor dial) identify this project and its official builds.

The GNU General Public License covers Recursa's code. It gives no rights to the name or the icon (GPL-3.0 section 7(e)).
This page explains what you can do with them. The aim is to let people trust that anything called Recursa came from
this project.

## Without asking

- Say that your software works with, is based on, or is a fork of Recursa.
- Redistribute official, unmodified Recursa builds under the Recursa name and icon.
- Use the name and icon to refer to the project in articles, reviews, tutorials and talks.

## Not without written permission

- Distribute a modified version under the name Recursa or with the Recursa icon. A fork needs its own name and its own
  icon: rename it in `crates/desktop/tauri.conf.json`, the window titles and the UI, and replace the icons that
  `tools/icons.mjs` generates.
- Use the name or icon, or anything confusingly similar, in a product name, app store listing, domain name or social
  media account.
- Suggest that this project made, endorses or supports something it didn't.

## Other companies' marks

The CDN table shows the Akamai, Apple, Cloudflare, Fastly, Google, Meta, Microsoft and Amazon Web Services marks above each
network's name (the AWS mark stands for Amazon CloudFront), so the columns are easy to tell apart. The drawings come
from [Simple Icons](https://simpleicons.org) 16.34.0 (CC0), except Microsoft's four squares, which come from the
[SVG Logos](https://github.com/gilbarbara/logos) collection (CC0) and are flattened to one color. The marks belong to
their owners. The GPL doesn't cover them, and showing them doesn't mean those companies made, endorse or support
Recursa. The resolver and network names used throughout the app are likewise their owners' marks.
